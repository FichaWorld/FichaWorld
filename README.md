  ## Документация к сборке FichaWorld

**Установка сборки:**
 1. Открываем FileZilla, и вводим хост и имя с вашего хостинга (В Settings вашей панели будет SFTP details).
 2. Потом переносим с зип-файла FichaWorld все файлы в правое окно FileZilla, и дожидаемся полной установки.
 3. Ставми на панеле: Java17, создаем парочку бд MySQL (если нету докупите).
 4. После установки пройдитесь по папкам, и где нужна будет БД MySQL, и поставьте ее. А если есть вариант SQlite бд можете оставить ее.
 5. Удалите все БД SQLite (.db) в папках для того чтобы удалить данные создателя сборки. Не удаляйте с папки LuckPerms и другие важные.
 6. Зайдите в папку Essentials и удалите от туда папку userdata, после чего можем запускать сборку.
 7. Удалите все миры.
 8. При запуске сервера заходим в /lp editor и удаляем всех игроков, и очищяем /deop.
 9. Если в консоли будут какие-то ошибки, то скопируйте и отправьте их в https://claude.ai или https://chat.deepseek.com, а не писать в ЛС владельцу

**Часто задаваемые вопросы по сборке:**
 1. Вопрос: Почему ивенты спавняться на больших координатах?
 <img width="486" height="121" alt="image" src="https://github.com/user-attachments/assets/743a4eff-b83b-4533-b336-65f49fc635f9" />

 Ответ: Нужно установить границу мира меньше, например 3000х3000

 2. Вопрос: Как очистить топы?

 Ответ: /ajl reset <выбираете топ>, потом в чате нажмите Confirm

 3. Как создать/выдать/потдвердить заявку на создание кастомного титула, и кастомной привилегии

 Ответ: Для открытия меню кастомного титула - /customtitul, для открытия меню списка заявок - /tituladmin. Для открытия меню создания кастомной привилегии /custompriv, для открытия меню списка заявок - /privadmin. Для выдачи жетонов команда /fichacustompriv (там и титул и привилегию можно).

 4. Вопрос: Как создать свой промокод?

  Ответ: Создать промокод можно в плагине FichaPromoCode

 5. Вопрос: Как выдать кейсы?

  Ответ: Выдать кейсы можно через команду /holycases (aliases /hc)

 6. Вопрос: Как выдать себе кастомные предметы?

  Ответ: Есть несколько плагинов, для выдачи трапок,стана,светильника джейка, ком снега, команда /holyliteitems. Для выдачи золотого спавнера, золотой кирки джейка, загадочного яйца, команда /hgs (золотой спанвер) и /hce (загадочное яйцо). Для выдачи гравитации, вампиризма (предметы кипера), имеется команда /holyexpkeeper give

 7. Вопрос: Как выдать универсальный ключ?

  Ответ: Выдать универсальный ключ, или заспавнить какой-то данж можно командой /kotikdang

 8. Вопрос: Как выдать контейнер?

  Ответ: Выдать контейнер можно командой /container give

 9. Вопрос: Как выдать себе коины в /excange?

  Ответ: выдать можно через команду /coins

 10. Вопрос: Как настроить лут?

  Ответ: Настроить лут можно через команду /lm

 11. Вопрос: Как выдать себе привелегию?

  Ответ: Для выдачи привилегии есть команду /lp

 12. Вопрос: Как выдать сапфиры?

  Ответ: Выдать сапфиры можно командой /p give <ник> <количество>

 13. Вопрос: Как выдать себе например меч етернити, или сохранить какой-то предмет?

  Ответ: Можно через команду /si, если нужно выдать то /si give <ник> <название предмета> <количество>, посмотреть весь список можно через /si list, а чтобы сохранить /si save
